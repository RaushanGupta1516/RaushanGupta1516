> **The most ambitious thing I've built** — a dual-dashboard AI hiring platform with **13 distinct LLM-powered features**, built solo from idea to production.

### What it does

| 🧑‍💼 For Recruiters | 👤 For Job Seekers |
|---|---|
| AI Job Description Generator | Job Match Scoring |
| Resume Screening & Ranking | Skill Gap Analysis |
| Candidate Comparison | AI Mock Interviews |
| Interview Kit Builder | Cover Letter Generator |
| + more AI tools | + more AI tools |

### How it's built

```
┌──────────────────────────────────────────────────────────────────┐
│  🤖  Llama 3.3 70B via Groq API — engineered prompts per tool    │
│  🔐  Google OAuth 2.0 + JWT in httpOnly cookies (secure auth)    │
│  🗂️  Role-based dashboards + protected routes                    │
│  📁  Cloudinary-powered resume/file upload pipeline              │
│  🔔  Real-time notifications across recruiter & seeker sides     │
│  🚀  Independently architected and shipped to production         │
└──────────────────────────────────────────────────────────────────┘
```
